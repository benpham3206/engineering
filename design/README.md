# design

Turning a need into something that works, can be built, and can be explained.

## Topics

- Design process: requirements, concepts, selection, iteration
- Engineering graphics: sketching, orthographic views, sections
- CAD: parts, assemblies, drawings
- GD&T and tolerancing
- Machine elements: shafts, bearings, gears, fasteners, springs
- Design for manufacturing and assembly
- Factor of safety and failure analysis
- Mechatronic systems
