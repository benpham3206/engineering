# design

Turning a need into something that works, can be built, and can be explained.

**Prerequisites:** none for the first three lessons ([Design process](01-design-process.md), [Engineering graphics](02-engineering-graphics.md), and [CAD](03-cad.md)), so they can start in the first semester. The later lessons need [math](../math/README.md) (algebra and trigonometry), [physics](../physics/README.md) (forces and motion), and [materials](../materials/README.md) (stress basics).

## Lessons

Study order:

- [Design process](01-design-process.md): requirements, concepts, selection, iteration
- [Engineering graphics](02-engineering-graphics.md): sketching, orthographic views, sections
- [CAD](03-cad.md): parts, assemblies, drawings
- [GD&T and tolerancing](04-tolerancing-and-stack-up.md): limits, fits, stack-up
  - [GD&T symbols and frames](05-gdt-symbols-and-frames.md): datums, feature control frames, characteristic symbols
  - [GD&T material conditions and position](06-gdt-material-conditions-and-position.md): MMC, LMC, RFS, bonus tolerance, position
- [Factor of safety and failure](07-factor-of-safety-and-failure.md): stress, yield, von Mises
- Machine elements:
  - [Shafts and bearings](08-shafts-and-bearings.md): torsion sizing, bearing life
  - [Gears, fasteners, and springs](09-gears-fasteners-and-springs.md): gear geometry, bolt preload, spring rate
- [Design for manufacturing and assembly](10-design-for-manufacturing-and-assembly.md)
- [Mechatronic systems](11-mechatronic-systems.md): sensors, actuators, control loops
