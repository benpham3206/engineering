# Sources

**Type:** data

Every source that a constant, property, or claim in the repo rests on. Only free, public, well-known sources go here, so any reader can check the claim without paying or logging in. Each claim names its source by key and gives an exact locator (section, table, article, page, or object number).

`Group` names who stands behind the source. Two sources count as independent only when their groups differ: two articles in one encyclopedia are one group. `Archive` is a snapshot of the page in a public web archive, so the claim stays checkable if the page moves; `pending` means none has been recorded yet.
