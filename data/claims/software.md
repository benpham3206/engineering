# Software claims

**Type:** data

Facts about software: what a program, library, or function does, its interface, and its version. Software changes fast, so these claims use layer `dated`, with `As of` and a `Review by` date about one year ahead. The algorithm a call runs is timeless and lives in the math or simulation sheets; only the call and its behavior in a named version are registered here. Field rules are in [VERIFICATION.md](../../VERIFICATION.md#claims).
