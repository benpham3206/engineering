# data

The canonical facts the rest of the repo rests on: one fact, one place. Lessons and reference sheets round these values and cite these claims; `python verify.py` checks that they agree. How each table is used is in [VERIFICATION.md](../VERIFICATION.md).

## Tables

- [Units](units.md): every unit the verifier understands, defined from the SI base units
- [Constants](constants.md): physical constants and Earth conventions, plus the prose scans that catch disagreeing values
- [Properties](properties.md): material and fluid properties with conditions
- [Sources](sources.md): every free, public source a value or claim rests on
- [Claims](claims/README.md): dated and attributed facts, each with sources, status, and who checked it
