# math

The language engineering is written in. Most of the work here is knowing which tool fits the problem and checking that the answer makes sense.

## Topics

- Algebra
- Trigonometry
- Calculus: limits, derivatives, integrals, series
- Multivariable calculus: partial derivatives, gradients, multiple integrals, vector calculus
- Linear algebra: matrices, systems of equations, eigenvalues
- Differential equations: first-order, second-order, systems, Laplace transforms
- Probability and statistics
- Numerical methods: root finding, integration, ODE solvers, error
- Software solvers: MATLAB, Python, spreadsheets, calculators
