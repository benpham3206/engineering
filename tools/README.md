# tools

The software, hardware, and calculators that make engineering work faster.

**Prerequisites:** [Algebra and functions](../math/README.md) for the computation and calculator lessons. [Measurement](../measurement/README.md) is useful before the shop lesson. Start with the starter kit.

## Lessons

1. [Starter kit](01-starter-kit.md): the minimal, mostly free toolset for a self-taught engineer
2. [Python](02-python.md): free calculations, arrays, and solvers
3. [Spreadsheets](03-spreadsheets.md): tables, formulas, and quick "what if" checks
4. [GNU Octave and MATLAB](04-matlab.md): matrix computing, with a free Octave route
5. [Calculators](05-calculators.md): when to use one instead of code, and how to use one without silent errors
6. [CAD: SolidWorks and free alternatives](06-cad-solidworks.md): parametric modeling, with FreeCAD and Onshape
7. [Measurement tools](07-measurement-tools.md): reading tools, resolution, and tolerance stacks
8. [Shop tools](08-shop-tools.md): surface speed, RPM, and machine safety
9. [Free engineering software](09-free-software.md): free and open-source CAD, FEA, CFD, MATLAB alternatives, circuits, fabrication, and documentation tools
10. [Drafting and layout tools](10-drafting-and-layout-tools.md): scales, compass and dividers, protractors, squares, sketching, and laying out on metal
11. [Machinist bench tools](11-machinist-bench-tools.md): workholding, indicators and edge finders, taps and tap drills, reamers, files, and hand tools
12. [Software skills for engineers](12-software-for-engineers.md): terminal, Git, scripts, tests, debugging, automating CAD, and web basics
