# Starter kit

**Type:** lesson

A short list of tools a self-taught engineer can get started with on a tight budget. Most of the list is free. The paid items are optional and you can skip them until a course or project needs them.

**Prerequisites:** [Python lesson](02-python.md) for the software parts. Otherwise none.
**Time:** 2-3 h to set up everything in this list

## Core ideas

- Start with free software. A free tool you use every week beats an expensive one you never open.
- Buy hardware only when a project needs it. Borrow, rent, or use the school or library shop first.
- Keep one notebook or folder for all work. Engineers are judged on their records as much as their answers.
- Check that every tool runs on your own computer before you pay for anything.

The list below is in the order most learners need the items.

- **Computer with a spreadsheet.** Any laptop works. Use a free spreadsheet such as LibreOffice Calc or Google Sheets for tables and quick checks.
- **Python with Jupyter.** Python is free and does most calculations you will meet. Jupyter gives you a notebook where you can mix code, notes, and results. The official install guide is at [jupyter.org/install](https://jupyter.org/install). Install with `pip install jupyterlab` and start it with `jupyter lab`.
- **GNU Octave.** A free program that runs most MATLAB-style code. Use it if your course uses MATLAB and you do not have a license. See the [manual index](https://docs.octave.org/latest/).
- **FreeCAD.** Free, open-source 3D CAD. It is the free alternative to SolidWorks. See [freecad.org](https://www.freecad.org/).
- **Onshape free plan.** A browser-based CAD tool with a free plan. Read the [pricing page](https://www.onshape.com/en/pricing) before you use it. The free plan is for non-commercial use, and all documents on it are public. Do not put private or client designs there.
- **Scientific calculator.** One that handles fractions, exponents, logs, and trig. It is for exams and quick checks. A graphing calculator is useful, but only buy one if your course requires it. The [HP Prime lesson](05-hp-prime.md) explains what a graphing calculator adds.
- **Measuring tools.** A steel rule, a tape measure, and a digital caliper cover most early work. See the [measurement lesson](07-measurement-tools.md) before you buy.
- **Safety glasses and hearing protection.** Cheap, and needed in any shop. The [shop tools lesson](08-shop-tools.md) covers when to use them.
- **Notebook or lab book.** Paper or digital. Date every entry and write down the units.

## Key equations

None. This lesson is a checklist.

## Worked example

**Given:** A learner has $600 for tools over one year and no shop access.

**Find:** Which items to buy first.

**Assumptions:** The learner uses a personal laptop and has no course software.

**Solution:**

1. Install free software first: Python, Jupyter, FreeCAD, Octave. Cost: $0.
2. Buy a digital caliper and a steel rule for measurement practice.
3. Keep the remaining budget for a course-specific item or a shop day pass.

**Answer:** Start with free software and a caliper. The rest of the budget can wait until a project asks for it.

**Sanity check:** The free items cover the software needs for the first two years of most coursework. The hardware items are cheap compared with the budget.

## Practice

1. Write down which items on the list you already have.
2. Install Python and run a line that prints `hello`. Save a screenshot.
3. Open FreeCAD and draw a 50 mm by 50 mm square in its sketcher.
4. Measure the thickness of a sheet of paper with a caliper. Note the reading and its unit.
5. Make a one-page budget with a free item column and a paid item column.

## Common mistakes

- Buying expensive software before checking for a free version.
- Buying a graphing calculator that the course does not allow on exams.
- Putting private designs on a public-document plan.
- Skipping the notebook, then forgetting which numbers came from which test.
- Buying precision tools before learning the basic reading and handling skills.
