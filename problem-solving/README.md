# problem-solving

A repeatable way to work through problems you have not seen before.

## Topics

- Define the problem: knowns, unknowns, assumptions
- Draw it: sketches, free-body diagrams, schematics
- Pick the governing principles
- Solve symbolically before plugging in numbers
- Check units and limiting cases
- Sanity-check the answer: order of magnitude, sign, intuition
- Estimation
- Debugging when it does not work
