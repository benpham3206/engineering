# engineering

everything i learned as a mechanical engineering student at SJSU

A timeless engineering reference. Lessons to learn from, reference sheets to work from, and principles that stay true whatever we end up building.

## What is engineering?

Engineering is using math, science, and experience to design and build things that solve real problems, with constraints like cost, safety, time, and materials.

Science asks how the world works. Engineering asks what we can make with that knowledge, and whether it will hold up.


## Who are engineers?

An engineer is a problem solver who applies scientific principles, mathematical logic, philosophical reasoning, and creative ingenuity to design, build, and optimize practical solutions for human needs. 

## Advice

1. Learn the fundamentals.
2. Practice daily.
3. Apply engineering in your day-to-day life.
4. Build with wonder.
5. Build for the future.

## How to use this

Every file is one of three types, marked at the top:

- **Lesson.** The numbered files in each folder. Each one teaches a topic from scratch, with a worked example and practice problems.
- **Reference.** The `reference` files in each folder. Each one is a dense lookup sheet for working engineers, with equations and the limits where they stop being true, typical values, rules of thumb, and checklists.
- **Philosophy.** The principles behind good engineering. Start with [Principles that last](philosophy/07-principles-that-last.md).

If you are **learning**, follow the [roadmap](ROADMAP.md): four years of lessons and projects, laid out like a mechanical engineering degree.

If you are **working**, go straight to the reference sheets in the table below.

## Built to last

This repo is written to stay useful for a very long time, so it follows a few rules:

- **First principles over products.** Laws of physics and methods come first. Software and tools are named as examples and dated, because they will change.
- **SI units first.** With the assumptions written out, including which planet's gravity.
- **Models are simplified representations of reality.** Formulas have their limits.
- **Plain text.** Markdown and open formats that any person or computer can read.
